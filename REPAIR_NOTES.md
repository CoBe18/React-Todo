# My Everyday Todo List repairs
The deployed source is the CoBe-Beebe branch, not master. Preserve the original Solitude artwork and styling. Task changes now persist in browser storage, blank tasks are rejected, Enter submits a task, and task toggles support keyboard input.
Use Node 22.12+; npm ci; npm test; npm run build. Publish dist using the included netlify.toml. Review a preview before publishing. Browser-local tasks do not sync between devices.
